액션: $ARGUMENTS

`.agent-context/tickets/*.md` 와 `TODO.md` 로 추적 건을 관리한다.

## 액션

### (없음) 또는 `list`
1. `tickets/*.md` 스캔
2. status가 `in_progress` 또는 `blocked` 인 것만 수집
3. 미완료 체크리스트 추출
4. `TODO.md` 자동 재생성 후 표시

### `add`
신규 등록. **비블로킹 즉시 등록이 원칙** — 묻지 말고 맥락에서 자동 결정한다.
- 키: 티켓 키가 언급됐으면 그것, 없으면 `{영역}-{슬러그}` 자동 생성
- 요약: 요청 원문에서 추출 (원문은 본문에 보존)
- 체크리스트: 파악된 만큼만. 로직 파악 전이면 `- [ ] 로직 파악` 하나로 시작해도 된다

```markdown
---
key: {KEY}
title: {요약}
status: in_progress
created: YYYY-MM-DD
---
상태: 가설

## 요청 원문
## 출처
## 파악한 것
## 체크리스트
- [ ] 로직 파악
```

### `resume`
중단된 작업의 컨텍스트를 복원한다. 티켓 본문 + 연결된 `deep`·`qa-log`를 함께 읽어
"어디까지 했고 다음에 뭘 할지"를 요약한다.

### `{KEY}`
해당 티켓 한 건만 표시.

## 졸업
운영 반영 + 확정 검증이 끝나면 `/kb-save`로 `deep/`에 동작 지식을 남기고,
티켓 상태를 `졸업(→ deep/xxx.md)` 으로 바꾼 뒤 본문을 짧은 후기와 포인터로 트림한다.
