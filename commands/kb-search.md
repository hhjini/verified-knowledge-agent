키워드: $ARGUMENTS

**코드를 훑기 전에 반드시 먼저 실행한다.**

## 검색 순서

1. **진단 레시피** (`deep/voc-*.md`) — 증상형 문의면 0순위
2. **영역 분석** (`deep/*.md`) — 관련 영역의 동작 지식
3. **처리 기록** (`qa-log/*.md`) — 유사 과거 건
4. **추적 건** (`tickets/*.md`) — 진행 중이거나 파킹된 건
5. **Layer 1 인덱스** — 시작점 탐색

## 출력

각 히트마다 다음을 표시한다.
- 파일 경로와 **상태**(확정 / 부분확인 / 가설 / 반증)
- 한 줄 요약
- 이번 문의와 어떻게 관련되는지

**상태 표시가 없는 항목은 미검증으로 취급해 그렇게 표시한다.**
`반증` 항목이 나오면 왜 틀렸는지와 올바른 값을 함께 보여준다.

## 못 찾았을 때 (miss loop)

"없음"으로 끝내지 않는다.
1. 타겟 코드를 직접 확인한다 (콜드 스캔 금지, 인덱스가 가리키는 곳만)
2. 있으면 → 처리 후 `deep/`에 쌓는다
3. **없으면 → "코드에 없음"도 기록한다.** 같은 막다른 길을 다시 파지 않기 위해
